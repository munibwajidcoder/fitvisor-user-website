# FitVisor - Virtual Try-On with True Precision

> **Try. Explore. Find your style.**  
> Ultra-realistic 3D digital twins and neural fabric simulation designed to solve the online fashion return crisis.

---

## 🌟 Key Features

- **3D Virtual Try-On Studio (`/3d-studio`)**: 360° rotatable try-on pedestal with real-time lighting presets.
- **Fabric Tension Heatmap (`/3d-studio/tension`)**: Physics-accurate stretch and fit analysis with live biomechanical feedback.
- **Multi-Garment Layering (`/3d-studio/layering`)**: Combine jackets, tops, pants, and footwear into complete ensembles.
- **Side-by-Side Fit Comparison (`/3d-studio/compare`)**: Compare Size M vs Size L with synchronized rotation.
- **Interactive Catalog & PDP (`/catalog`, `/product`)**: Seamless filtering, try-on actions, and curated capsules.
- **Social Opinion & Ask a Friend (`/3d-studio/ask-friend`)**: Real-time look voting and styling advice.
- **Verified Community Feed (`/community`)**: Real buyer looks without deceptive filters.
- **Order Flow & Boutique Kiosks (`/cart`, `/checkout`, `/order-success`)**: In-store reservation QR codes.
- **Biometric Data Vault & Privacy (`/profile`)**: Full GDPR Article 17 compliance, Anonymous Mode, and data export.
- **Welcome Landing Page (`/welcome`)**: High-impact brand experience with partner brands (Balmain, Zalando, H&M, Sandro, Shein).

---

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI / Styling**: Vanilla CSS & Design Tokens (Pixel-accurate fidelity)
- **Icons**: Clean inline SVG iconography
- **Assets**: High-resolution curated fashion imagery and 3D avatar visualizers

---

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.
