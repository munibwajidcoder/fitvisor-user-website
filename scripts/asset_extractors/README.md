# Asset Extraction and Processing Tools

This directory contains standalone PowerShell utility scripts used during development to extract, crop, and inspect asset images from specification documents and media files.

## Contents
- **`extract_*_assets.ps1`**: Helper scripts for extracting and sizing image assets for various pages (Catalog, 3D Studio, Layering, Compare, Tension, Ask a Friend, Wardrobe, Order).
- **`crop_precise_*.ps1`**: Exact coordinate cropping utilities for specific avatar, cart, and QR code assets.
- **`inspect_*.ps1` / `check_*.ps1`**: Validation and pixel-dimension checking scripts for generated and cropped assets.
